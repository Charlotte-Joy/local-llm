# Model tiers for install.sh / install.ps1 (chosen October 2026 from independent benchmarks).
#
# One section per use: "[name] description". The installer asks which use matters most (or takes --use).
# Each row: min_budget_GB  light  medium  heavy
# The installer uses the highest row whose min_budget is <= the machine's memory budget.
# Every model is under ~80% of its row's budget, leaving room for the context window.
#
# A cell may list fallbacks separated by "|": the first tag that exists on ollama.com is used.
# "-" means no model for that tier.
# On Apple Silicon, a plain tag like qwen3.8:27b is swapped for its MLX build (qwen3.8:27b-mlx)
# when one is published and is about the same size. Tags with an explicit variant (like -q8_0) are left alone.
#
# Evidence (fetched 2026-10-11):
#   coding  - Artificial Analysis (Terminal-Bench 2.1, tau2-bench tool calling), Vals.ai SWE-bench and
#             LiveCodeBench, LiveBench, swebench.com. Devstral, gpt-oss and qwen3-coder were dropped for
#             weak independent agentic / tool-calling results.
#   writing - EQ-Bench Creative Writing v3 and Longform, LMArena creative writing.
#   vision  - Artificial Analysis MMMU-Pro, LMArena vision, Vals.ai MMMU.
# Image generation is left out: Ollama removed it in 0.32.6 (Aug 2026) and it isn't back as of 0.40.2.
